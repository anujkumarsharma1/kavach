# KAVACH

Finds text hidden in the lowest bit of a model's weights, and removes it. It runs entirely in your browser, so the model file never leaves your device.

**Live:** https://anujkumarsharma1.github.io/kavach/

Built for the Precision Care Hackathon 2026. v2 (Oct 2026) replaces the Streamlit app with a static web app. The original app is kept in [`legacy/`](legacy/).

## What it does
Every weight in a model is a floating-point number. Overwriting only its least significant bit barely changes the value, so an attacker can spread a byte string (a malware signature, credentials, a C2 address) across thousands of weights. The model still loads and predicts normally. Pickle scanners such as ModelScan and Fickling check whether *loading* a file runs code. They don't read the weight values, so a string hidden there passes them.

Kavach:
1. **Reads the file as data.** A `.pt`/`.pth` file is a zip holding a pickle. Kavach walks the pickle opcode by opcode, without unpickling and without running anything. That gives it every tensor's dtype, shape, stride and storage, wherever the tensor sits: a flat state_dict, a nested training checkpoint, or a whole pickled `nn.Module`. A `.safetensors` file is read straight from its JSON header.
2. **Flags dangerous imports.** If the pickle references something like `os.system`, `posix.system`, `builtins.eval` or `subprocess.*`, the verdict is **Dangerous**.
3. **Scans every fp32, fp16 and bf16 tensor** (fp64 too). It takes bit 0 of each element and packs those bits into bytes at all 8 bit alignments. It then slides a 64-byte window in 8-byte steps and flags any window that is at least 75% printable ASCII. Random bits are about 37% printable (95 of 256 byte values). A flagged region that contains the EICAR test string is marked "Known signature"; any other flagged region is marked "Unknown text".
4. **Disarms.** It randomises bit 0 of every flagged tensor and downloads all tensors as `<name>.kavach-clean.safetensors`. The cleaned file is re-scanned before the download starts.
5. **Exports a JSON report** of the verdict, findings, per-tensor peaks and skipped tensors.

## Supported files
- `.pt` / `.pth` in the zip format that `torch.save` has written since PyTorch 1.6: state_dicts, nested checkpoints, whole pickled models, including non-contiguous tensors.
- `.safetensors`.
- Scanned dtypes: fp32, fp16, bf16, fp64. Integer and bool tensors are listed as skipped.

## Limits
- Strings shorter than about 48 bytes can't fill 75% of a 64-byte window, so they are missed. Encrypted or compressed strings are missed too, because they don't look like text. So is data hidden in higher bits.
- Casting a model between dtypes (fp32 to fp16, for example) rewrites the lowest bits and destroys any string that was hidden before the cast.
- Not supported: legacy pre-1.6 `.pt` files, compressed or big-endian archives, `.bin`, ONNX, GGUF and Keras.
- The list of dangerous imports is a blocklist. "Clean" means no hidden text was found and no listed dangerous import was seen. It doesn't prove the file is safe to load.
- Disarm always writes `.safetensors`, never back to `.pt`. The whole cleaned file is held in memory, and very large tensors need roughly their own size in free browser memory.

## Development
    cd web
    npm ci
    npm test          # parity with the Python reference + malformed-file tests
    npm run build
    npx playwright test

    pip install -r tools/requirements.txt
    python tools/make_samples.py                         # regenerates fixtures, samples and expected.json
    python tools/measure_accuracy.py imagenette2-160/val

`tools/kavach_ref.py` loads files with `torch.load(weights_only=False)`. Only run it on files generated by `make_samples.py`.

Every push to `main` runs the tests and deploys `web/dist` to GitHub Pages (`.github/workflows/pages.yml`).

## Layout
    web/src/core/pickle.ts       opcode reader that never unpickles, plus the dangerous-import list
    web/src/core/torchzip.ts     .pt/.pth zip and tensor discovery
    web/src/core/safetensors.ts  safetensors header reader
    web/src/core/scan.ts         LSB window scan
    web/src/core/disarm.ts       writes the cleaned .safetensors file
    web/src/worker.ts            runs scans off the main thread
    web/src/main.ts              UI
    tools/                       Python reference, sample generator, accuracy measurement
    legacy/                      the original Streamlit app (retired)
