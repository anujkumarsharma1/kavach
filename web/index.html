How it works

1

Read without running

Files are parsed as data. The pickle inside a .pt file is walked opcode by opcode and nothing in it is executed. If it would call something like os.system when loaded, the verdict is Dangerous.

2

Collect the lowest bits

Every fp32, fp16 and bf16 weight gives up its least significant bit. Those bits are packed into bytes at all 8 possible alignments, because a hidden string can start anywhere.

3

Look for text

A 64-byte window slides in 8-byte steps. Ordinary weights produce noise that is roughly 37% printable. A window that is 75% printable or more is flagged, and one containing the EICAR test signature is marked critical.

Disarming doesn't change what the model predicts

We hid 5 strings in an ImageNet ResNet18, then disarmed it. On all 3,925 Imagenette validation images, the tampered and the disarmed model gave the same prediction as the original for every image. Top-1 accuracy stayed at 66.83% in all three cases, and the largest change to any weight was 1.5×10−8.

Measured 14 Oct 2026 with tools/measure_accuracy.py, torchvision ResNet18 IMAGENET1K_V1, Imagenette 160px validation split. Raw output: accuracy_result.json.

What it won't catch

  • Strings shorter than about 48 bytes, or encrypted or compressed ones, because they don't look like text.
  • Data hidden in higher bits, or in integer or quantised tensors, which are listed as skipped.
  • Pickle tricks outside its list of dangerous imports. Treat "Clean" as "no hidden text found", not as a guarantee that the file is safe.
